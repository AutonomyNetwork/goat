# Project Overview
Blay is a AI x Crypto Agent, where he will help users to do on chain actions using natural language processing using GOAT (Great Onchain Agent Toolkit). 


### Technical Specifications 
- Blay uses particle network to create web3 wallets for users. 
- User can use that wallet to interact with actions that we define using GOAT  

### User flow
- Once users open app, we have login/signup page using particle network, 
- Users use Email or Google OAuth to login into system. 
- Once user login we will have wallet create that assigned to create wallet client in GOAT
- User will land in chat page where he can do some action using his wallet.
- We have logout button, we he can logout.
